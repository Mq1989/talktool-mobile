TalkTool iOS Expo App - Twilio Voice React Native SDK Implementation Plan                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                             
 Overview                                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                             
 Replicate the full TalkTool web calling experience (outbound calls, incoming calls with availability management, real-time transcripts, translation toggle, DTMF, introductions, voicemail routing) in your existing Expo app using @twilio/voice-react-native-sdk v2.x     
 (Expo-native), connecting to the same backend (numberlang-server) and Next.js API.                                                                                                                                                                                          
                                                                                                                                                                                                                                                                             
 ---                                                                                                                                                                                                                                                                         
 Architecture Mapping: Web SDK → React Native SDK                                                                                                                                                                                                                            
 ┌─────────────────────────────┬──────────────────────────────────────────┬───────────────────────────────────────────────┐                                                                                                                                                  
 │        Web (JS SDK)         │             React Native SDK             │                     Notes                     │                                                                                                                                                  
 ├─────────────────────────────┼──────────────────────────────────────────┼───────────────────────────────────────────────┤                                                                                                                                                  
 │ new Device(token)           │ new Voice()                              │ Voice is a singleton, no token in constructor │                                                                                                                                                  
 ├─────────────────────────────┼──────────────────────────────────────────┼───────────────────────────────────────────────┤                                                                                                                                                  
 │ device.register()           │ await voice.register(token)              │ Async, token passed here                      │                                                                                                                                                  
 ├─────────────────────────────┼──────────────────────────────────────────┼───────────────────────────────────────────────┤                                                                                                                                                  
 │ device.connect({ params })  │ await voice.connect(token, params)       │ Token passed per-call                         │                                                                                                                                                  
 ├─────────────────────────────┼──────────────────────────────────────────┼───────────────────────────────────────────────┤                                                                                                                                                  
 │ device.on('incoming', conn) │ voice.on(Voice.Event.CallInvite, invite) │ CallInvite object                             │                                                                                                                                                  
 ├─────────────────────────────┼──────────────────────────────────────────┼───────────────────────────────────────────────┤                                                                                                                                                  
 │ conn.accept()               │ await callInvite.accept()                │ Async                                         │                                                                                                                                                  
 ├─────────────────────────────┼──────────────────────────────────────────┼───────────────────────────────────────────────┤                                                                                                                                                  
 │ conn.reject()               │ await callInvite.reject()                │ Async                                         │                                                                                                                                                  
 ├─────────────────────────────┼──────────────────────────────────────────┼───────────────────────────────────────────────┤                                                                                                                                                  
 │ conn.disconnect()           │ await call.disconnect()                  │ Async                                         │                                                                                                                                                  
 ├─────────────────────────────┼──────────────────────────────────────────┼───────────────────────────────────────────────┤                                                                                                                                                  
 │ conn.mute(bool)             │ await call.mute(bool)                    │ Async, returns new state                      │                                                                                                                                                  
 ├─────────────────────────────┼──────────────────────────────────────────┼───────────────────────────────────────────────┤                                                                                                                                                  
 │ conn.sendDigits(str)        │ await call.sendDigits(str)               │ Same behavior                                 │                                                                                                                                                  
 ├─────────────────────────────┼──────────────────────────────────────────┼───────────────────────────────────────────────┤                                                                                                                                                  
 │ conn.customParameters       │ callInvite.customParameters              │ Map of custom params                          │                                                                                                                                                  
 ├─────────────────────────────┼──────────────────────────────────────────┼───────────────────────────────────────────────┤                                                                                                                                                  
 │ conn.parameters.CallSid     │ call.getSid()                            │ Different access pattern                      │                                                                                                                                                  
 ├─────────────────────────────┼──────────────────────────────────────────┼───────────────────────────────────────────────┤                                                                                                                                                  
 │ N/A (web push)              │ voice.initializePushRegistry()           │ iOS VoIP push (required)                      │                                                                                                                                                  
 └─────────────────────────────┴──────────────────────────────────────────┴───────────────────────────────────────────────┘

 Step 3: Initialize Voice SDK and Register                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                             
 Initialization flow (equivalent to useEffect in DeviceContext that creates the Device):                                                                                                                                                                                     
                                                                                                                                                                                                                                                                             
 useEffect(() => {                                                                                                                                                                                                                                                           
   const setup = async () => {                                                                                                                                                                                                                                               
     try {                                                                                                                                                                                                                                                                   
       setStatus("requesting-permissions");                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                             
       // iOS: Initialize PushKit for VoIP push notifications                                                                                                                                                                                                                
       if (Platform.OS === "ios") {                                                                                                                                                                                                                                          
         await voice.initializePushRegistry();                                                                                                                                                                                                                               
       }                                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                                             
       // Fetch token from your existing API                                                                                                                                                                                                                                 
       const token = await fetchAccessToken();                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                             
       // Register for incoming calls                                                                                                                                                                                                                                        
       await voice.register(token);                                                                                                                                                                                                                                          
       setStatus("registered");                                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                             
       // Set up event listeners (see Step 4)                                                                                                                                                                                                                                
       setupEventListeners();                                                                                                                                                                                                                                                
     } catch (e) {                                                                                                                                                                                                                                                           
       setError(e.message);                                                                                                                                                                                                                                                  
       setStatus("error");                                                                                                                                                                                                                                                   
     }                                                                                                                                                                                                                                                                       
   };                                                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                                                             
   setup();                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                             
   return () => {                                                                                                                                                                                                                                                            
     voice.unregister();                                                                                                                                                                                                                                                     
   };                                                                                                                                                                                                                                                                        
 }, []);                                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                                             
 Token fetching (reuses your existing /api/accessToken endpoint):                                                                                                                                                                                                            
                                                                                                                                                                                                                                                                             
 const fetchAccessToken = async () => {                                                                                                                                                                                                                                      
   const clerkToken = await getToken(); // From @clerk/clerk-expo                                                                                                                                                                                                            
   const res = await fetch(`${API_BASE_URL}/api/accessToken`, {                                                                                                                                                                                                              
     method: "POST",                                                                                                                                                                                                                                                         
     headers: {                                                                                                                                                                                                                                                              
       "Content-Type": "application/json",                                                                                                                                                                                                                                   
       "Authorization": `Bearer ${clerkToken}`,                                                                                                                                                                                                                              
     },                                                                                                                                                                                                                                                                      
     body: JSON.stringify({ identity: user.id }),                                                                                                                                                                                                                            
   });                                                                                                                                                                                                                                                                       
   const data = await res.json();                                                                                                                                                                                                                                            
   return data.token;                                                                                                                                                                                                                                                        
 };

The same token works for the React Native SDK.

 Step 4: Event Listeners (Incoming Calls)                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                             
 Equivalent to device.on('incoming', conn) in DeviceContext (lines 947-1037):                                                                                                                                                                                                
                                                                                                                                                                                                                                                                             
 const setupEventListeners = () => {                                                                                                                                                                                                                                         
   // Incoming call invite (equivalent to device 'incoming' event)                                                                                                                                                                                                           
   voice.on(Voice.Event.CallInvite, (callInvite) => {                                                                                                                                                                                                                        
     // Extract custom parameters (same as web: parentCallSid, srcLang, dstLang, etc.)                                                                                                                                                                                       
     const customParams = callInvite.customParameters;                                                                                                                                                                                                                       
     const parentCallSid = customParams?.parentCallSid;                                                                                                                                                                                                                      
     const srcLang = customParams?.srcLang;                                                                                                                                                                                                                                  
     const dstLang = customParams?.dstLang;                                                                                                                                                                                                                                  
     const incomingNumber = customParams?.incomingNumber;                                                                                                                                                                                                                    
     const isTranslatingParam = customParams?.isTranslating;                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                             
     // Store parentCallSid (critical - this is the session key on the backend)                                                                                                                                                                                              
     parentCallSidRef.current = parentCallSid;                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                             
     // Set languages                                                                                                                                                                                                                                                        
     setCallLanguages({ srcLang: srcLang || "en-US", dstLang: dstLang || "en-US" });                                                                                                                                                                                         
                                                                                                                                                                                                                                                                             
     // Set incoming state                                                                                                                                                                                                                                                   
     setIncomingCallInvite(callInvite);                                                                                                                                                                                                                                      
     setCallState("incoming");                                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                             
     // Play incoming ring sound (use expo-av or similar)                                                                                                                                                                                                                    
     playIncomingRing();                                                                                                                                                                                                                                                     
   });                                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                             
   // Call invite cancelled (caller hung up before answer)                                                                                                                                                                                                                   
   voice.on(Voice.Event.CancelledCallInvite, (cancelledInvite) => {                                                                                                                                                                                                          
     stopIncomingRing();                                                                                                                                                                                                                                                     
     setIncomingCallInvite(null);                                                                                                                                                                                                                                            
     setCallState("idle");                                                                                                                                                                                                                                                   
   });                                                                                                                                                                                                                                                                       
 };

 const acceptIncomingCall = async () => {                                                                                                                                                                                                                                    
   if (!incomingCallInvite) return;

   setCallStartTime(Date.now());                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                             
   // Accept the call                                                                                                                                                                                                                                                        
   const call = await incomingCallInvite.accept();                                                                                                                                                                                                                           
   setActiveCall(call);                                                                                                                                                                                                                                                      
   setCallState("active");                                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                             
   // Extract parentCallSid from custom parameters                                                                                                                                                                                                                           
   const customParams = incomingCallInvite.customParameters;                                                                                                                                                                                                                 
   const parentCallSid = parentCallSidRef.current || customParams?.parentCallSid;                                                                                                                                                                                            
   const effectiveCallSid = parentCallSid || call.getSid();                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                             
   // Set translation state from custom params                                                                                                                                                                                                                               
   const shouldTranslate = customParams?.isTranslating === "true";                                                                                                                                                                                                           
   setIsTranslating(shouldTranslate);

   setCallInfo({                                                                                                                                                                                                                                                             
     direction: "inbound",                                                                                                                                                                                                                                                   
     from: customParams?.incomingNumber || "Unknown",                                                                                                                                                                                                                        
     to: "",                                                                                                                                                                                                                                                                 
     callSid: effectiveCallSid,                                                                                                                                                                                                                                              
   });                                                                                                                                                                                                                                                                       
   setCallSid(effectiveCallSid);                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                             
   // Set up call event listeners (see Step 7)                                                                                                                                                                                                                               
   setupCallEventListeners(call);                                                                                                                                                                                                                                            
                                                                                                                                                                                                                                                                             
   setIncomingCallInvite(null);                                                                                                                                                                                                                                              
 };

 Step 6: Making Outbound Calls                                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                             
 Equivalent to startCall() in voice-call page.jsx (lines 347-467):                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                             
 const startCall = async ({ dialNumber, repLang, customerLang, callerIDNumber, translateInitially, initialMessage, translatedMessage }) => {                                                                                                                                 
   resetTranscript();                                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                                                             
   try {                                                                                                                                                                                                                                                                     
     const token = await fetchAccessToken(); // Fresh token                                                                                                                                                                                                                  
     setCallState("dialing");                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                             
     // Connect with same params as web app                                                                                                                                                                                                                                  
     const call = await voice.connect(token, {                                                                                                                                                                                                                               
       To: dialNumber,                                                                                                                                                                                                                                                       
       repLang: repLang,              // e.g., "en-US"                                                                                                                                                                                                                       
       customerLang: customerLang,    // e.g., "es-ES"                                                                                                                                                                                                                       
       callerId: callerIDNumber,                                                                                                                                                                                                                                             
       gTranslateCode: LANG[customerLangKey]?.translateLang || "es",                                                                                                                                                                                                         
       clerkUserId: user.id,                                                                                                                                                                                                                                                 
       orgId: organization?.id || null,                                                                                                                                                                                                                                      
       translateInitially: String(translateInitially),                                                                                                                                                                                                                       
       initialMessage: translatedMessage || "",                                                                                                                                                                                                                              
       initialMessageOriginal: initialMessage || "",                                                                                                                                                                                                                         
     });                                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                                             
     setActiveCall(call);                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                             
     // Set call info (will be updated when parentCallSid arrives)                                                                                                                                                                                                           
     setCallInfo({                                                                                                                                                                                                                                                           
       direction: "outbound",                                                                                                                                                                                                                                                
       from: callerIDNumber,                                                                                                                                                                                                                                                 
       to: dialNumber,                                                                                                                                                                                                                                                       
       callSid: call.getSid(), // Browser leg SID initially                                                                                                                                                                                                                  
     });                                                                                                                                                                                                                                                                     
                                                                                                                                                                                                                                                                             
     // Set up call event listeners                                                                                                                                                                                                                                          
     setupCallEventListeners(call);                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                             
   } catch (e) {                                                                                                                                                                                                                                                             
     console.error("Call failed", e);                                                                                                                                                                                                                                        
     setCallState("idle");                                                                                                                                                                                                                                                   
   }                                                                                                                                                                                                                                                                         
 };                                                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                             
 Critical Note on parentCallSid: For outbound calls, the backend sends back parentCallSid as a custom parameter on the accepted call. In the React Native SDK, you access this via call.getCustomParameters() once the call is connected.

 Step 7: Call Event Listeners (Active Call)                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                             
 Equivalent to the conn.on('accept'), conn.on('disconnect'), etc. in voice-call page.jsx:                                                                                                                                                                                    
                                                                                                                                                                                                                                                                             
 const setupCallEventListeners = (call) => {                                                                                                                                                                                                                                 
   // Call connected (equivalent to 'accept' event)                                                                                                                                                                                                                          
   call.on(Call.Event.Connected, () => {                                                                                                                                                                                                                                     
     setCallState("active");                                                                                                                                                                                                                                                 
     setCallStartTime(Date.now());                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                             
     // Get parentCallSid from custom parameters                                                                                                                                                                                                                             
     const customParams = call.getCustomParameters?.();                                                                                                                                                                                                                      
     const parentCallSid = customParams?.parentCallSid || parentCallSidRef.current;                                                                                                                                                                                          
     const effectiveCallSid = parentCallSid || call.getSid();                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                             
     setCallSid(effectiveCallSid);                                                                                                                                                                                                                                           
     setCallInfo(prev => ({ ...prev, callSid: effectiveCallSid }));                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                             
     // Create call record (same as web)                                                                                                                                                                                                                                     
     createCallRecord(effectiveCallSid);                                                                                                                                                                                                                                     
   });                                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                             
   // Call ringing                                                                                                                                                                                                                                                           
   call.on(Call.Event.Ringing, () => {                                                                                                                                                                                                                                       
     setCallState("call-ringing");                                                                                                                                                                                                                                           
   });                                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                             
   // Call disconnected                                                                                                                                                                                                                                                      
   call.on(Call.Event.Disconnected, () => {                                                                                                                                                                                                                                  
     setActiveCall(null);                                                                                                                                                                                                                                                    
     setCallState("ended");                                                                                                                                                                                                                                                  
     setIsMuted(false);                                                                                                                                                                                                                                                      
   });                                                                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                             
   // Call failed/error                                                                                                                                                                                                                                                      
   call.on(Call.Event.ConnectFailure, (error) => {                                                                                                                                                                                                                           
     console.error("Call failed:", error);                                                                                                                                                                                                                                   
     setCallState("idle");                                                                                                                                                                                                                                                   
     setActiveCall(null);                                                                                                                                                                                                                                                    
   });                                                                                                                                                                                                                                                                       
 };

 Step 9: WebSocket Connection for Transcripts & Translation                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                             
 Reuse the exact same WebSocket logic from DeviceContext (lines 692-896).                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                             
 The display WebSocket connects to the backend at:                                                                                                                                                                                                                           
 wss://{BACKEND_URL}/call/display?callSid={parentCallSid}                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                             
 Messages received (same as web):                                                                                                                                                                                                                                            
 - transcript → Add to transcript array                                                                                                                                                                                                                                      
 - call-initiated → Update call state                                                                                                                                                                                                                                        
 - call-ringing → Update call state                                                                                                                                                                                                                                          
 - call-answered → Set active, store languages, set isTranslating                                                                                                                                                                                                            
 - end-call → Set ended state                                                                                                                                                                                                                                                
 - toggle-translation.ack → Update isTranslating state                                                                                                                                                                                                                       
 - translation-state-sync → Sync translation state on connect                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                             
 Messages sent (same as web):                                                                                                                                                                                                                                                
 - { type: "call.join", callSid } → Join the call room on connect                                                                                                                                                                                                            
 - { type: "ping", ts } → Heartbeat every 25s

 Critical Implementation Notes                                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                             
 1. parentCallSid is the Session Key                                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                             
 The backend uses parentCallSid (the original Twilio call SID) as the session key for everything: WebSocket rooms, translation state, transcript routing. Never use the mobile SDK's local call SID for API calls - always extract and use parentCallSid from custom         
 parameters.                                                                                                                                                                                                                                                                 
                                                                                                                                                                                                                                                                             
 2. iOS VoIP Push Must Be First                                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                             
 On iOS, voice.initializePushRegistry() MUST be called before voice.register(). This sets up PushKit for receiving call notifications when the app is killed/backgrounded.                                                                                                   
                                                                                                                                                                                                                                                                             
 3. Token Per Call                                                                                                                                                                                                                                                           
                                                                                                                                                                                                                                                                             
 Unlike the JS SDK where the token is set once on the Device, the React Native SDK requires passing the token on each voice.connect() call. Always fetch a fresh token before connecting.                                                                                    
                                                                                                                                                                                                                                                                             
 4. Background Limitations                                                                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                             
 iOS limits background execution. The heartbeat (30s interval) won't run reliably in background. Consider:                                                                                                                                                                   
 - Using expo-background-fetch with minimum interval (iOS allows ~15min minimum)                                                                                                                                                                                             
 - Accepting that availability TTL (120s) may expire when app is backgrounded for extended periods                                                                                                                                                                           
 - Re-registering availability on AppState change from background → active                                                                                                                                                                                                   
                                                                                                                                                                                                                                                                             
 5. CallKit Integration (iOS)                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                             
 The Twilio React Native SDK v2.x automatically integrates with CallKit on iOS. This means:                                                                                                                                                                                  
 - Incoming calls show the native iOS call screen                                                                                                                                                                                                                            
 - The app can receive calls even when terminated (via VoIP push)                                                                                                                                                                                                            
 - Call audio is automatically managed by the system                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                             
 6. Same Backend, No Changes Needed                                                                                                                                                                                                                                          
                                                                                                                                                                                                                                                                             
 The backend (googlestt.js) doesn't need any changes. It already:                                                                                                                                                                                                            
 - Sends custom parameters (parentCallSid, srcLang, dstLang, incomingNumber, isTranslating) when dialing the client                                                                                                                                                          
 - Handles the display WebSocket for transcripts                                                                                                                                                                                                                             
 - Processes translation-on/off messages                                                                                                                                                                                                                                     
 - Routes calls based on agent availability in Redis                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                                             
 The only requirement is that the mobile app uses the same Clerk userId as identity so the backend can route calls correctly.
